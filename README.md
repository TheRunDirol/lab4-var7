# Лабораторная работа №4

## Вариант 7

Пакет `fueltrip` предназначен для расчёта параметров поездки.

### Функции

- `FuelNeeded` — рассчитывает необходимое количество топлива.
- `TripCost` — рассчитывает стоимость топлива.
- `AddTrafficReserve` — добавляет запас топлива в процентах.
- `FormatTripReport` — формирует отчёт о поездке.

### Используемые технологии

- Go
- Git
- GitHub
- `github.com/fatih/color`
- `github.com/google/uuid`

go run ./cmd/app
